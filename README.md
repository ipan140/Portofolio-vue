---

## 📌 Features

- 👤 **Interactive Profile Card**: Profile avatar, bio, quick social links, and one-click direct CV download (`CV_Ivano_Rossi_Sugiyanto.pdf`).
- 🛠️ **Tech Stack & Skills Showcase**: Highlights 40+ technologies, frameworks, libraries, and tools across Frontend, Backend, Database, and DevOps.
- 💼 **Experience & Education Timeline**: Interactive career and educational journey at Telkom University and industry roles (CEBES Indonesia, etc.).
- 🚀 **Projects Gallery**: Showcase of fullstack, frontend, and backend projects with search filters and tech badges.
- 📜 **Certifications & Publications**: Verified credentials, professional certifications, and research publications.
- 🎨 **Modern UI/UX**: Built with Tailwind CSS and PrimeVue with dark mode and custom theme support.
- ⚡ **Ultra Fast**: Powered by Vite and Vue 3 Composition API (`<script setup>`).

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed:
- Node.js `^20.19.0` or `>=22.12.0`
- npm `^10.0.0` or later

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ipan140/Portofolio-vue.git
   cd Portofolio-vue
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.

---

## 📦 Build & Deployment

### Type-Check & Build for Production
```bash
npm run build
```

The compiled and minified assets will be generated in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
